# T2Rhythm 5.5.499.1312 — 인기 곡 재생·캐시 갱신·음성 모델 설치

## 인기 리스트에서 듣기와 다운로드

내 보관함에 일치하는 곡이 있으면 재생 아이콘을 표시하고, 곡을 누르면 기존 플레이어에서 재생합니다. 제목과 아티스트를 정규화해 대조하고, 같은 이름의 여러 음원이 있으면 앨범을 함께 확인합니다. 라이브·리믹스 등 제목이 다른 버전은 합치지 않습니다. 여러 앨범 중 어느 곡인지 판단하기 어려우면 자동으로 고르지 않습니다. 보관함 대조 색인은 화면 밖에서 만들며, 준비되기 전에는 다운로드를 시작하지 않습니다.

없는 곡은 YouTube·SoundCloud·직접 입력한 HTTPS 음원을 확인해 **저장 없이 재생**하거나 **음원 다운로드**할 수 있습니다. 재생만 선택하면 보관함에 음원 파일을 게시하거나 다운로드 작업을 만들지 않습니다. 재생 중에는 기존의 제한된 임시 오디오 캐시를 사용할 수 있습니다.

YouTube와 SoundCloud는 잠시 유효한 주소 대신 원래 소스 주소를 큐에 보관하고, Media3의 로딩 스레드에서 재생 주소를 해석합니다. 해석 결과는 최대 24개·2분간 재사용합니다. 큐 복원이나 이후 재생 때 주소를 다시 해석할 수 있습니다.

곡의 다운로드 아이콘은 대기·다운로드 중에 진행 표시로 바뀝니다. 앨범에도 해당 수록곡의 다운로드 상태를 반영합니다. 앨범 다운로드를 선택하면 인기 리스트에 포함된 수록곡을 보여 주고, 각 곡의 음원을 확인해 선택합니다. 이미 있는 곡은 재생하며, 다운로드는 화면을 이동해도 계속됩니다. 전체 앨범의 모든 수록곡을 수집하는 기능은 아닙니다. 취소·재시도는 기존 백그라운드 다운로드 화면에서도 가능합니다.

진행률이 바뀔 때마다 과거 다운로드 파일 전체를 다시 읽지 않습니다. 새 음원이 보관함 스캔에 반영되기 전에도 최근 완료한 다운로드에서 재생할 수 있습니다.

## 이미지와 가사 수정 후 즉시 반영

이미지 수정 뒤 Coil 메모리·디스크 캐시, 음원 아트 추출 캐시, 색상·위젯 이미지를 갱신합니다. 이미지 요청에는 영구 보관하는 세대 번호를 붙여, 이전에 시작한 요청이 늦게 끝나도 새 이미지 대신 재사용하지 않게 합니다. 현재 표시 중인 이미지와 플레이어·알림의 이미지 주소도 갱신합니다. 직접 고른 이미지를 복사할 때는 이전 원본 캐시를 건너뜁니다.

연속된 일괄 편집의 캐시 갱신 요청은 300ms 모아서 처리합니다. 캐시를 갱신하려고 전체 보관함을 다시 스캔하거나 이미지 세대 번호만 바뀐 모든 곡을 데이터베이스에 다시 쓰지 않습니다. 앱의 캐시 지우기도 같은 갱신 신호를 사용합니다. 원본 음원·수동 이미지·영구 가사·백업은 유지하고, 진행 중인 다운로드의 이어받기 파일과 열린 이미지 캐시 저널은 일반 파일 삭제에서 제외합니다.

늦게 끝난 음원 기술 정보·장르 분석이 사용자가 수정한 제목·아티스트·앨범·이미지·장르를 되돌리는 경합도 방지합니다. 기술 정보는 해당 열만 갱신하고, 장르는 분석 시작 후 사용자가 바꾸지 않은 경우에만 반영합니다. 삭제·이동한 음원을 오래된 분석 결과로 복원하지 않습니다. 동시 기술 정보 추출은 최대 2개로 제한합니다.

가사를 편집하면 이전 조회를 취소하고, 수정한 일반 가사보다 오래된 동기 가사가 우선 표시되지 않게 합니다. 자동 가사 수집을 꺼도 직접 검토·수정한 가사는 영구 저장합니다. 늦게 도착한 자동 조회가 검토한 가사를 덮지 못하게 보호하고, 블루투스 가사의 파싱 상태도 초기화합니다. 앞으로 저장하는 가사 캐시에는 한글을 밑줄로 바꾸는 파일명 대신 아티스트·제목의 해시를 사용합니다. 기존 저장 파일은 보존하며 읽기 호환성을 유지합니다.

## 멈춰 보이던 한국어 음성 모델 다운로드

모델 다운로드·설치를 가사 분석과 분리합니다. 사용자가 다운로드하면 모바일 데이터를 포함한 인터넷 연결과 저장 공간이 있는 상태에서 시작합니다. 약 87MB를 다운로드하고 약 265MB를 설치합니다. 이전 버전의 충전·Wi-Fi 조건을 기다리는 작업은 앱 시작 때 작업 ID를 유지하며 갱신해 이어받을 수 있게 합니다.

다운로드, 검증·설치, 대기, 실패 상태와 진행률·취소를 구분해 표시합니다. 전체 크기와 SHA-256을 검증하고 경로 이탈·압축 해제 크기를 제한한 뒤 임시 폴더에서 설치를 완료합니다. 설치는 낮은 우선순위에서 작은 작업 구간마다 쉬고, 충전 여부 때문에 검증·압축 해제를 처음부터 반복하지 않습니다. 실제 가사 타이밍 분석의 충전·유휴 조건은 유지합니다.

## 검증

검증 결과와 실제 Android 화면은 [화면 검증 기록](validation/v1312/REPORT.md)에 정리합니다. 자동 테스트와 소프트웨어 에뮬레이터 결과는 삼성 실기기의 성능 측정을 대신하지 않습니다.
