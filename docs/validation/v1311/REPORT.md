# T2Rhythm 5.5.499.1311 검증 기록

Android API 29 에뮬레이터의 실제 MainActivity에서 기존 보관함과 검색 탭을 사용했습니다. 720×1280px·320dpi, 한국어, 기본 글꼴과 시스템 글꼴 배율 1.3입니다. 세 곡과 앨범·가수는 재현 가능한 화면 검증 데이터이며 실제 파일 태그를 바꾸지 않습니다.

## 실제 화면과 동작

- [보관함 음질 필터](filters.png): 손실 압축·표준 음질을 기존 필터 행에 한국어로 표시합니다.
- [검색 시작 화면](discover.png): 초성·복합 검색 안내, 개인 검색어와 기존 장르 탐색을 함께 사용합니다. 장르가 있으면 큰 시작 장식을 접어 실제 탐색 항목을 먼저 보여 줍니다. 장르 카드의 곡 수도 ‘2곡’처럼 기존 한국어 리소스로 표시합니다.
- [초성 검색](initials.png): `ㅅㄹㅈㅇㅇ`로 ‘서른 즈음에’와 해당 수록 앨범을 찾습니다.
- [제목·가수 조합 검색](tokens.png): `김광석 편지`에서 ‘이등병의 편지’만 곡 결과로 표시합니다.
- [글꼴 1.3과 빈 결과](large-font.png): 검색어를 유지하고 결과가 없음을 표시합니다. 스트리밍 연결 요구는 나타나지 않습니다.

첫 캡처에서 기존의 긴 검색 시작 제목이 한국어 단어 중간에서 여러 줄로 끊기고 입력창 안내도 두 줄이 되는 것을 확인했습니다. 시작 문구를 짧은 제목과 보조 설명으로 나누고, 입력창 안내를 짧은 한 줄로 바꿨습니다. 글꼴이 커진 편집창에서 긴 입력은 가로로 이동하며 지우기와 필터 조작은 유지합니다. 화면 재생성 뒤에도 검색어를 확인합니다.

캡처는 앱 소유의 접근성 창인지 검사한 뒤 실제 화면 전체를 저장합니다. MainActivity 조작은 ActivityScenario·UiAutomation과 실제 Android 시계를 사용합니다.

## 자동 검증

- 단위 테스트 314개: 앱 262개·크롤러 52개. 한국어 초성·분리 자모·띄어쓰기·전각/대소문자·기기 언어·관련성 순서·검색 취소를 확인합니다.
- 5만 항목 색인과 검색 취소를 검증합니다. 10만 이벤트를 필요한 순간 생성하는 Reader로 공급하고, 전체 입력을 읽기 전에 소비를 시작하며 한 묶음이 128건을 넘지 않는지 확인합니다. 삼성 실기기의 속도나 메모리 측정 수치라는 뜻은 아닙니다.
- Android 고유 사례 58개: 기존 53개, 기록 이전·복구 2개, 비동기 검색 상태 2개, 실제 앱 검색 탐색 1개입니다.
- 손상된 입력의 유효한 128건을 남긴 뒤 129건으로 복구하여 정확히 재개하는지 확인합니다. 재시도 뒤 저널 줄 수와 청취 횟수가 늘지 않으며 원본 파일은 동일하게 남습니다. 호환 기록 함수로 추가한 새 청취도 통계에 반영됩니다.
- 파생 데이터베이스를 다시 만들었을 때 새로 이전한 저널에서 재생 횟수와 청취 시간이 복구되는지 확인합니다.
- 빠른 검색어 변경·원본 제목 수정·종류 필터 해제 시 이전 결과를 표시하지 않는지 검사합니다. 앨범의 수록곡 제목 검색과 곡별 중복 장르 집계도 확인합니다.

첫 Android 전체 실행에서는 57개가 통과하고 새 검색 상태 사례 하나가 실패했습니다. 이 사례는 테스트의 Compose 본문에서 앨범과 플레이리스트를 만들면서 기본 생성 시각이 계속 바뀌어 입력이 매번 변경되는 구성이었습니다. 데이터를 본문 밖의 고정 목록으로 옮긴 뒤 검색 상태 사례 2개와 실제 앱 탐색을 다시 실행해 모두 통과했습니다. 앱의 ViewModel이 제공하는 라이브러리 목록과 같은 수명으로 검증했습니다. 실제 앱 탐색에서도 시작 시 예약된 MediaStore 새로고침이 시험용 목록을 교체하는 경합을 확인해, 초기 준비가 끝난 뒤 시험 목록을 넣도록 했습니다. 마지막 곡 수 번역을 포함한 실제 앱 탐색도 최종 단독 실행에서 통과했습니다.

## 범위

하드웨어 가속 없는 소프트웨어 에뮬레이터입니다. 삼성 Android 17/API 37 실기기의 발열·배터리·대규모 라이브러리 반응 시간은 직접 측정하지 못했습니다. 앱은 compile/target SDK 37로 빌드합니다. 이번 변경에 실제 YouTube 연결이나 다운로드 검증을 새로 수행했다는 의미는 없습니다.

서명된 난독화 Release와 CI, 인증서·16KB 정렬·Rhino/Vosk/JNA 실행, 게시 APK 해시 확인 결과는 PR의 최종 검증 기록에 연결합니다. [사용 안내](../../LIBRARY_SEARCH_1311.md)에 검색 규칙과 데이터 보존 동작을 정리합니다.
