# 5.5.499.1312 검증 기록

## 범위와 환경

실제 MainActivity·탐색·플레이어·Room 데이터베이스·WorkManager·Coil을 사용하는 Android 회귀 검증입니다. API 29 x86_64 에뮬레이터, 720×1280, 320dpi, 기본 글꼴 및 1.3배 글꼴에서 실행했습니다. 하드웨어 가속 없는 소프트웨어 에뮬레이션이므로 실행 시간은 실제 기기의 성능 수치가 아닙니다.

## 자동 검증

- 단위 테스트: 앱 264개 + 크롤러 52개, 총 316개 통과.
- Android 기존 회귀 38개와 이번 변경 관련 27개 통과. 모델 전체 설치, 설치 무결성, 이어받기·취소, HLS, 영구 저장, 직접 수정한 가사 보호를 포함합니다.
- 최종 디버그 APK의 추가 확인: 메타데이터 편집 경합, 같은 경로 이미지 즉시 변경, 실제 인기 탭 재생 흐름 통과. 기존 한국어 검색·화면 복원까지 4개 모두 통과. 이전 실행의 중복을 제외하면 Android 68개 항목을 검증했습니다.
- 최초 화면 테스트에서는 실제 MediaStore 재스캔이 가상의 음원 ID를 대체하고 이전 대기열이 남는 문제가 있어, 인기 화면 테스트를 실제 보관함 음원으로 변경했습니다. 검증 중 실제 제품의 오래된 분석 스냅샷 덮어쓰기도 발견해, 기술 정보 열만 갱신하고 장르 변경을 조건부 적용하도록 수정한 뒤 재검증했습니다.
- `:crawler:test :app:testGithubDebugUnitTest :app:assembleGithubDebug :app:assembleGithubDebugAndroidTest`: 성공.
- 서명 APK·R8 네이티브 로딩·16KB 정렬 및 전체 CI는 게시 전에 별도 검사합니다.

## 외부 서비스와 한계

SoundCloud는 실제 서비스 검색·오디오 주소 추출·HLS 재생 목록(HTTP 200, 11개 구간)을 확인했습니다. 공식 한국어 Vosk 모델은 HEAD 및 범위 다운로드(206), 고정 SHA-256을 확인했고, 충전하지 않은 Android 환경에서 전체 설치와 네이티브 모델 열기를 검증했습니다.

이 환경에서 YouTube 실서비스 연결은 네트워크 CONNECT 403으로 확인하지 못했습니다. 삼성 Android 17 실기기의 재생·다운로드와 성능은 별도 확인이 필요합니다. 앨범 다운로드는 인기 목록에 포함된 곡별 소스를 확인하는 기능이며, 전체 앨범의 모든 곡을 별도로 수집하지 않습니다.
