# T2Rhythm 베이스 앱과 기능 패키지

현재 T2Rhythm의 네이티브 화면과 기능을 베이스 앱 위에서 실행한다. 웹뷰로 전환하지 않으며, 아이콘을 누르면 기존 음악 앱이 열린다. Android 8 이상을 유지한다.

- 최초 실행용 음악 기능을 APK에 내장하여 오프라인 실행과 복구에 사용한다.
- 업데이트 화면에서 변경 내역을 확인하고 다운로드를 선택한 뒤, 적용을 별도로 확인한다. 승인 전에는 새 코드를 실행하지 않는다.
- 승인한 기능은 다음 안전한 **새 프로세스의 앱 시작**에 적용한다. 음악·공유·작업이 실행 중인 프로세스는 현재 버전을 유지하며, 화면만 다시 여는 것으로 버전을 바꾸지 않는다.
- 음악 접근 권한부터 안내하고 카메라·Bluetooth·위치·마이크는 해당 기능을 처음 사용할 때 요청한다. Android의 필수 권한·페어링 확인은 유지한다.
- 최초 설치와 실제 베이스 변경에는 Android APK 설치 확인이 필요하다. 호환되는 일반 기능 업데이트는 APK를 설치하지 않는다.
- 서명·해시·호환성을 검증하며, 시작에 실패한 업데이트는 이전 정상 버전으로 복구한다. 손상된 적용 기록은 기본 포함 버전 복구 화면에서 명시적으로 복구할 수 있다. 음악과 설정을 초기화하지 않는다.

`:app`은 고정 베이스, `:runtime-content`는 기존 음악 구현이다. Android 컴포넌트 이름·앱 ID·배포 서명·데이터 경로를 유지한다. 변경 내역·버전 표시·다운로드 진행은 기존 업데이트 화면에 연결한다. 새 권한·공용 SDK·베이스 연결 변경은 별도의 APK 갱신이 필요하다.

[구현과 빌드/서명 절차](runtime/NATIVE_APP_PORT.md), [패키지 형식](runtime/PACKAGE_FORMAT_V1.md), [검증 기록](runtime/NATIVE_VALIDATION_20261024.md)을 참고한다. 전체 기능·디자인 보존 검증이 끝나기 전에는 이 전환을 완료된 릴리스로 표시하지 않는다.
