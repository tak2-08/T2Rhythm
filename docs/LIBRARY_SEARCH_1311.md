# T2Rhythm 5.5.499.1311 — 보관함 검색과 오래된 기록

## 한국어로 더 쉽게 찾기

검색 탭에서 곡·앨범·아티스트·플레이리스트를 기존 방식으로 찾을 수 있습니다. 여기에 한국어 초성 검색과 띄어쓰기 생략 검색을 더합니다.

- `ㅅㄹㅈㅇㅇ` 또는 `서른즈음에` → **서른 즈음에**
- `김광석 편지` → 제목과 가수를 함께 확인해 **이등병의 편지** 검색
- `ㄱㄱㅅ Folk` → 가수 초성과 장르 조합

한글 자모가 분리된 이름과 전각 영문도 정규화합니다. 검색어의 모든 단어가 맞는 항목을 찾고, 제목이 정확히 일치하거나 제목으로 시작하는 항목을 먼저 표시합니다. 앨범은 수록곡 제목으로도 찾을 수 있습니다. 현재 선택한 결과 종류 필터는 계속 적용합니다.

검색어와 종류 필터는 화면 재생성 시 복원됩니다. 키보드의 검색 버튼을 누르면 검색어를 최근 검색에 남기고 키보드를 닫습니다. 결과를 누르지 않고 검색어를 바꾸는 동안 이전 결과를 잘못 누르는 일을 막습니다. 결과가 없는 상태와 아직 찾는 중인 상태를 구별합니다.

## 처리 비용 줄이기

검색 화면에 있는 동안만 메모리에 검색용 색인을 유지합니다. 원본 라이브러리는 변경하지 않습니다. 곡·앨범·아티스트·플레이리스트별로 자료가 바뀐 색인만 다시 만듭니다. 입력할 때마다 전체 이름을 소문자로 다시 변환하지 않습니다.

색인 생성과 검색은 화면 스레드 밖의 작업 하나로 제한합니다. 입력을 120ms 모아 처리하고, 새로운 입력이나 메타데이터 변경이 생기면 이전 작업을 취소합니다. 순위는 작은 네 개 묶음을 사용해 전체 결과 정렬 비용을 줄입니다. 원본 보관함 순서는 같은 관련성 안에서 유지합니다.

장르 목록과 곡 수는 곡마다 한 번 순회해 함께 만듭니다. 이전처럼 장르 하나마다 전체 곡을 다시 세지 않습니다. 곡 안에서 대소문자만 다른 같은 장르는 한 번만 셉니다.

## 오래된 청취 기록 이전

이전 Rhythm 형식인 `playback_history.json`을 처음 가져올 때 파일 전체와 전체 이벤트 목록을 메모리에 동시에 만들던 경로를 바꿉니다. 스트림으로 읽고 최대 128건씩 현재의 영구 저널과 데이터베이스에 저장합니다. 디스크 동기화도 묶어 수행합니다.

이미 가져온 이벤트는 안정적인 식별자로 확인하므로 중간 종료 후 재시도해도 청취 횟수를 늘리지 않습니다. 전체 문서를 끝까지 읽은 뒤에만 이전 완료로 표시하며, 원본 파일을 보존합니다. 손상된 파일은 유효한 앞부분을 보존하고 실패 상태를 로그에 남깁니다. 같은 파일을 반복해서 읽으며 부하를 주지 않도록 5분간 기다리고, 파일이 수정되면 즉시 다시 시도합니다.

이전 호환 기록 함수도 현재 저널로 직접 저장합니다. 이미 이전이 끝난 예전 배열 파일에 새 기록을 덧붙여 통계에서 빠지는 문제와 배열 전체를 다시 쓰는 비용을 제거합니다. 기존의 서비스 청취 기록 수집 방식은 유지합니다.

## 표시 다듬기

장르가 있는 보관함에서는 큰 시작 장식을 접고 추천 검색어와 장르 목록을 바로 보여 줍니다. 입력창 안내를 짧게 바꾸고 한 줄 안에 표시합니다. 검색 시작 안내도 짧은 제목과 보조 설명으로 나누어 좁은 화면에서 긴 제목이 여러 줄로 쪼개지는 일을 줄입니다.

장르 카드의 곡 수도 공통 번역·복수형 리소스로 표시합니다. 보관함의 손실 압축·표준 음질·고음질·무손실·고해상도 무손실·스튜디오 마스터·CD 음질·서라운드 필터를 한국어로 표시합니다. 내부 필터 식별자는 유지하므로 저장된 선택과 분류 규칙이 바뀌지 않습니다.

실제 화면과 검증 범위는 [1311 검증 기록](validation/v1311/REPORT.md)에 정리합니다.
