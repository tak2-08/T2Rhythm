# 이미지·영상 연결 보호와 개인 음악 경험

## 수동 아트워크 보호

수동 선택 이미지는 파일 내용의 해시를 이름으로 사용하는 변경 불가능한 파일로 저장합니다. 자동 정보 보관을 꺼도 수동 선택은 보존합니다. `music_metadata/artwork_choices`에 곡 파일 경로 기준으로 선택과 삭제 의사를 기록하고, 이 기록을 Room·MediaStore 이미지·자동 사이트 이미지보다 우선합니다. 기존 ID 기준 선택은 원래 곡을 확인할 수 있는 Room 행이 남아 있을 때 이전합니다. 다른 파일이 같은 MediaStore ID를 얻었다고 선택 이미지를 물려받지 않습니다.

내장 이미지 추출, 설정 변경, 재검색 결과 병합과 늦게 끝난 온라인 이미지 조회도 최신 선택을 다시 확인합니다. Room 재구축은 진행 중인 검색을 중단·대기하고, 수동 이미지와 영상 연결을 먼저 이전한 다음 파생 데이터베이스를 비웁니다. 사용자가 선택한 원본 파일을 캐시로 취급해 지우지 않습니다. 예전에 이미 덮어쓴 파일의 원래 바이트를 새로 만들어 복구하는 기능은 아닙니다.

## 영상 복구와 공간 관리

영상은 곡의 파일 경로를 기준으로 연결합니다. 이전 URI 연결은 재구축 전에 이전하며, 명시적으로 끊은 연결은 다시 살아나지 않습니다. 설정 → **뮤직비디오 보관함**에서 연결된 영상, 연결이 사라진 영상 파일과 용량을 확인하고 원하는 음원에 다시 연결할 수 있습니다. **영상 파일 삭제**는 실제 파일과 이를 공유하는 연결을 함께 제거합니다. 일반 연결 해제는 공유 파일을 보존합니다.

파일 이동으로 경로까지 바뀌거나 이전 버전에서 연결 정보가 이미 사라졌다면 보관함에서 다시 연결하세요. 제목만 비슷한 다른 곡에 자동 연결하지 않습니다.

## 음원·앨범 검색과 완료 항목 재생

다운로드 화면의 **음원 / 앨범 / 다운로드 목록** 탭과 검색 화면의 **음원·앨범 검색 및 다운로드**에서 인기 순위와 독립적으로 검색합니다. 제목과 아티스트를 함께 입력하고 YouTube 또는 SoundCloud를 선택합니다. YouTube 앨범은 음악 앨범 검색 필터를 사용하며, SoundCloud는 제공처 재생목록을 사용합니다. 공개 제공처가 반환한 수록곡을 확인한 뒤 개별 또는 앨범 전체를 다운로드합니다. 한 앨범은 최대 200곡으로 제한합니다.

앨범 구성과 순서는 별도 영구 목록으로 남습니다. 이미 다운로드한 같은 소스의 파일은 다시 받지 않고 재사용합니다. 같은 이름의 다른 앨범을 한 목록으로 섞지 않습니다. 완료된 음원과 앨범은 다운로드 화면에서 바로 재생합니다. 보관함 검색이 아직 끝나지 않아도 게시 완료 파일을 검증해 로컬 재생하며, 실패·미완성·이미 지워진 파일은 재생하지 않습니다. 모바일 데이터 사용은 명시적으로 선택합니다.

## AI 가사 싱크 제안과 검토

시간 정보가 없는 텍스트 가사가 있는 로컬 음원에서 가사 화면의 별 모양 **AI 가사 싱크 제안** 버튼을 사용합니다. 현재 가사를 별도 요청으로 보관하고 음원을 분석해 제안을 만듭니다. 기존 가사는 수락 전까지 변경하지 않습니다.

- 파형과 학습한 줄 간격은 낮은 신뢰도의 초안을 만듭니다. 음성을 인식한 결과로 표시하지 않습니다.
- 정밀/혼합 모드는 선택 설치한 기존 Vosk 음성 모델을 사용합니다. 현재 제공 모델은 한국어이며, 반주·랩·다른 언어에서 맞지 않을 수 있습니다.
- 분석은 기존 충전 또는 배터리 90% 이상·저부하 조건을 지킵니다. 대기 중임을 표시하며 충분한 근거가 없으면 성공한 것으로 표시하지 않습니다.
- 제안 화면에서 원래 시간과 새 시간을 비교하고, 줄을 들어 보거나 0.2초씩 앞뒤로 이동하고 현재 재생 위치로 맞출 수 있습니다. 순서를 거스르거나 음원 길이를 벗어난 시간은 거절합니다.
- **수락 / 거절 / 되돌리기**를 지원합니다. 원래 가사와 최초 예측, 수정 결과를 구분해 보관합니다. 제안 이후 원본이 편집되었다면 오래된 제안을 적용하지 않습니다. 거절한 같은 입력은 30일간 다시 제안하지 않습니다.

수락한 검토 사례는 같은 PCM 녹음에 한 표만 반영합니다. 최대 96곡·4MB의 최근 검토 사례, 최대 32곡·장르별 8곡의 학습 참고를 사용합니다. 파생 학습 색인은 최대 8,192행·싱크 자료 256곡으로 제한합니다. 원본 LRC는 음원 길이·가사 구간 비율·줄 순서·줄 간격·텍스트 검사를 통과한 경우 참고하며, 검토하지 않은 앱 생성 결과를 정답으로 재사용하지 않습니다.

녹음별 해시로 분리한 검증 자료는 학습에 넣지 않고, 최소 3곡에서 비교할 수 있을 때 줄 시간의 평균 오차를 계산합니다. 측정상 악화된 후보는 제외하고 이전 참고 모델을 유지합니다. 이는 참고 LRC와의 일치도이며 실제 노래의 정답률은 아닙니다. 자료가 부족하면 정확도 숫자를 표시하지 않습니다. 모든 노래에서 정확도가 계속 높아진다고 보장하지 않습니다.

## 알고리즘 관리와 보고서

설정 → **알고리즘 관리**는 관찰된 경향, 학습 관리, 데이터·기록으로 나뉩니다. 볼륨·지역·시간대·출력 기기·활동별 장르 경향, 추천 학습의 반응 수·긍정/부정 반응·예측 오차·지역/볼륨/시간대 가중치와, 가사 참고 자료 수·검증 오차·최근 학습 시각·저장량을 확인합니다. 위치는 익명 지역 묶음이며 볼륨은 기기·앱의 설정값이지 실제 음압이 아닙니다. 관찰하지 않은 상황과 자료가 부족한 정확도는 추정해서 채우지 않습니다. 기존 보관함 설정에서는 이 관리 화면으로 이동합니다.

통계의 **나의 음악 이야기**에서 월요일 시작 주간, 달력 월간, 달력 분기 보고서를 현재 기기 시간대로 조회하고 이전 기간으로 이동합니다. 실제 청취 시간, 중복되지 않는 재생 발생 수, 상위 곡·장르를 보여 줍니다. 기간 경계를 넘는 구간은 실제 청취량을 비례 배분하며 쉬었던 공백을 청취로 더하지 않습니다.

현재 파일을 확인할 수 있는 상위 곡을 재생하거나 이름을 붙여 일반 플레이리스트로 저장할 수 있습니다. **하이라이트 믹스**는 최대 8곡의 시작 위치와 15~45초 구간을 선택해 최대 2초의 equal-power 크로스페이드로 이어 듣는 미리 듣기입니다. 일반 재생을 일시정지하고 화면을 닫거나 앱을 떠나면 중단하며, 별도 음원 파일을 생성하지 않습니다.

재생목록의 마지막 저장은 화면 종료를 막지 않는 비동기 작업으로 마칩니다. 새 화면에서 재생목록을 불러오는 작업과 저장 작업은 같은 잠금으로 순서를 지키며, 백업을 만들 때는 저장 완료를 기다립니다.

검증 결과와 화면은 [검증 기록](validation/library-integrity/REPORT.md)에 정리합니다.

## 설치용 미리보기 APK

`githubPreview`는 릴리스와 같은 축소·최적화 설정을 쓰고 `chromahub.rhythm.app.preview`라는 별도 앱으로 설치합니다. 실행 아이콘 이름은 **T2Rhythm Preview**입니다. 현재 환경의 서명이 기존 배포 APK와 달라, 기존 앱을 삭제하거나 데이터를 지우지 않고 새 기능을 확인할 수 있도록 분리했습니다. 기존 앱의 청취 기록·설정은 자동으로 이전되지 않으며 기기의 음원 파일은 보관함 접근을 허용한 뒤 스캔합니다.

```sh
./gradlew :app:assembleGithubPreview \
  -PversionCodeOverride=554991314 \
  -PversionNameOverride=5.5.499.1314-preview.1
```

정식 앱을 덮어 설치하는 업데이트 APK는 기존 배포본과 같은 서명 키로 만들어야 합니다. 미리보기 APK는 Releases의 해당 미리보기 버전에 체크섬과 함께 제공합니다.
