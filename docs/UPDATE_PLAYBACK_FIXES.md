# 1326 업데이트 안내·로컬 재생·반복 표시 검증

버전은 5.5.499.1326 / 554991326이다. 기준은 1325의 `280db27`, 검증한 앱 코드는 `fbc161cbb5134c20af9478bcd771ea4a5fd8a22e`다.

## 변경 내용

- 업데이트 설명은 설치된 버전마다 한 번 앱 안에서 표시하고, 설정의 업데이트 화면에서 다시 연다. 앱에 한국어·영어 설명을 포함하고 설치 버전에 맞는 서버 설명도 캐시하므로 오프라인에서도 읽을 수 있다. 업데이트를 받는 중이거나 이미 최신 버전인 경우에도 설치된 버전의 설명을 다시 열 수 있다. 버전 표시를 눌러 다른 저장소의 브라우저 페이지를 여는 동작은 앱 안 설명으로 바꿨다.
- 이전 파서는 특정 영어 제목만 인식했다. 한국어·영어 제목, 일반 목록과 본문을 지원하도록 분리했다. 설치 기록에 설명이 비어 있으면 현재 버전의 설명을 채우며, 사용자가 삭제한 기록을 다시 만들지는 않는다.
- 자동 큐 복원에서 현재 MediaController의 큐를 우선한다. 연결 시뿐 아니라 저장된 곡을 비동기로 읽은 후에도 다시 확인하여 진행 중인 곡에 예전 재생 위치를 적용하지 않는다. 다른 곡의 파일 편집 완료 콜백도 현재 재생 곡의 위치를 바꾸지 않는다.
- Expressive 플레이어 두 레이아웃에서 뒤바뀌었던 반복 아이콘을 Media3 상수에 맞췄다. 숫자 `1`은 **현재 한 곡 무한 반복**, 숫자가 없으면 **전체 곡 반복**이다. `1회만 반복` 모드는 추가하지 않았다. 기존 꺼짐 → 전체 → 한 곡 순서와 활성 색상·배치는 유지한다.

## PR 전 검증

[최종 실행 40064608001](https://github.com/tak2-08/T2Rhythm/actions/runs/40064608001)의 아티팩트를 내려받아 개수와 상태를 확인했다. 실패·오류·건너뜀을 통과로 세지 않는다.

| 범위 | 결과 |
| --- | --- |
| 앱/crawler 단위 테스트 | 378 + 61 = 439개 통과, 실패·오류·건너뜀 0 |
| Android Lint | 오류 0, 경고 372, 힌트 4 |
| Android 10 / API29 | 25개 통과 |
| Android 15 / API35 Google ATD | 25개 통과 |
| Android 17 / API37.0 | 25개 통과 |

각 Android 버전의 25개는 실제 로컬 재생 1, 업데이트 안내 4, 플레이어 6, 메타데이터 4, 가사·업데이트 화면 8, 실제 앱의 장르 검색·인기곡 재생 각 1이다. 기존 파일 편집·가사 보존·표지와 영상·버튼 배치·일반 검색·장르 탐색·다운로드 표시를 함께 확인한다.

로컬 재생 검사는 실제 70초 MediaStore 음원을 MediaController로 20초 지점에서 재생한다. 예전 1초 위치를 두 자동 복원 경로에 전달하고, 다른 곡의 파일 편집 완료 콜백도 실행하여 현재 곡과 위치가 보존되고 뒤로 가는 불연속 이벤트가 없는지 검사한다. 사용자 휴대폰의 특정 파일을 직접 재현했다고 주장하지는 않는다.

안내 검사는 최초 표시·확인 후 재진입 시 미표시·설정에서 재열기·인터넷 없이 한국어 번들 설명 읽기·큰 글씨 1.8배에서 확인 버튼 접근·삭제한 기록 보존을 확인한다. 반복 검사는 합쳐진/일반 플레이어 레이아웃에서 세 상태를 실제로 전환한다. Android 10·17의 실제 화면 캡처에서 숫자 1과 안내 창의 가독성을 확인했다. Google ATD는 화면 출력을 비활성화하므로 해당 검사는 클릭·의미 정보·배치와 상태 검증이며 픽셀 증거로 사용하지 않는다.

## 검사 환경 보완

첫 실행에서 Android 15 인기곡 검사는 초기화 직후 지연 스캔이 완료되기 전에 빈 목록을 조회해 건너뛰어졌다. 실제 MediaStore 음원이 준비될 때까지 기다리고, 음원이 없으면 명확히 실패하도록 바꿨다. 건너뜀을 허용하지 않는다.

Android 17 에뮬레이터의 `c2.goldfish.vp8.decoder`가 기존 VP8 영상의 입력 버퍼를 거부한 로그도 확인했다. 실제 영상 재생·표면 크기·크롭 검사를 유지하면서, 테스트용 영상만 같은 해상도의 MPEG-4 Simple Profile/AAC로 제공하여 소프트웨어 디코더로 검증했다. 기존 H.264/VP8 자산과 앱의 영상 재생 코드는 바꾸지 않았다.

DB 스키마, 재생 속도·오디오 처리·크로스페이드 엔진, 음원 파일, 공유·QR·Bluetooth 전송은 변경하지 않았다. 자동 복원 방어와 반복 표시·업데이트 안내 이외의 재생 기능을 제거하지 않는다.

이전 앱에서도 업데이트 설명을 읽도록 1326 릴리스 본문은 기존 `**What's New:**` 제목과 한국어 항목을 함께 사용한다.
