# 업데이트 내역과 설치 APK 정리

1324부터 설정 → 업데이트 → **업데이트 내역 관리**에서 이 기기가 확인한 설치 버전, 설치 일시, 이전 버전과 저장된 변경 내용을 확인합니다. 개별 기록과 전체 기록을 지울 수 있습니다. 기록 삭제는 앱 버전을 되돌리거나 음악·플레이리스트를 지우지 않습니다. 최대 100개를 보관하며, 기록을 시작하기 전의 설치 내역을 임의로 만들어 표시하지 않습니다.

앱에서 APK를 받으면 ‘다운로드 완료’, 시스템 설치 화면을 열면 ‘완료 확인 대기’로 표시합니다. 설치 화면을 여는 것만으로 성공으로 처리하지 않습니다. 설치가 취소되거나 아직 끝나지 않았으면 APK를 남겨 다시 시도할 수 있습니다.

실제로 앱이 교체된 뒤 Android가 알려 주는 설치 버전과 일시를 확인합니다. 패키지 교체 수신 처리와 다음 앱 실행 시의 정리 작업이 완료된 설치 파일을 삭제하고 이력을 갱신합니다. 받기만 하고 설치하지 않은 버전을 건너뛰어 더 새 버전을 설치했다면 ‘더 새로운 버전으로 대체됨’으로 구분합니다.

정리 대상은 앱의 `verified-updates` 전용 폴더에 있는 같은 패키지·같은 서명의 APK 중 현재 설치 버전 이하인 파일입니다. 다음 버전의 APK, 검증되지 않은 파일, 다른 앱의 APK, 심볼릭 링크와 사용자의 일반 다운로드 폴더는 자동으로 지우지 않습니다. 이전 버전에서 전용 폴더에 남긴 설치 APK도 확인해서 정리합니다.

브라우저나 다른 앱으로 직접 받은 APK는 Android 저장소 권한과 설치 출처 정보의 제한 때문에 앱이 임의로 찾아 삭제하지 않습니다. 이 경우에는 해당 앱이나 파일 관리자에서 삭제해야 합니다. 앱 삭제나 데이터 초기화는 기기의 업데이트 이력도 초기화합니다.
