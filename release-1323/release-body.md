T2Rhythm 5.5.499.1323 — 내 폰이 음악 서버로

설정 → **T2Rhythm Streaming**에서 서브폰의 음악을 메인폰이나 승인한 친구의 기기에서 들을 수 있습니다. 두 폰 모두 이번 버전을 설치하세요.

- **폰에서 실행**: 전체 음악 또는 선택한 플레이리스트를 공유하고 서버를 시작합니다. 별도 Debian 설치는 필요 없습니다.
- **연결하기**: 서버에서 만든 초대를 붙여 넣고, 두 폰에 표시된 숫자를 확인해 서버에서 승인합니다. 초대는 10분 동안 한 기기만 사용할 수 있습니다.
- 곡·아티스트·앨범 검색, 장르 필터, 대기열·셔플, 재생 위치 이동을 지원합니다. 실제 재생은 기존 청취 통계와 보고서에도 이어집니다.
- 서버의 음악 정보·공유 목록·표지 변경을 반영하고, 같은 경로의 표지를 교체한 경우에도 새 표지를 불러옵니다. 공유받은 곡의 물리 파일 수정은 서버 폰에서 합니다.
- 암호화된 TLS 연결과 서버 인증서 확인, 기기별 접근 취소, 암호화한 연결 정보 보관을 지원합니다. 공유받은 음원은 일반 음원 디스크 캐시에 저장하지 않습니다.
- 서버 알림에서 언제든 중지할 수 있습니다. 충전하지 않고 배터리가 15% 미만이면 서버를 중지합니다.

**외부에서 사용하려면** 개인 VPN 또는 직접 연결 가능한 주소 설정이 필요합니다. 앱이 중앙 릴레이를 제공하거나 공유기 포트를 자동으로 열지는 않습니다. 이미 연결한 서버는 주소 변경으로 갱신할 수 있습니다.

[자세한 연결·전원·캐시 안내](https://github.com/tak2-08/T2Rhythm/blob/5.5.499.1323/docs/PRIVATE_STREAMING.md)

기존 T2Rhythm 키로 서명합니다. 일반 사용자는 T2Rhythm-5.5.499.1323.apk를 설치하세요. 디버그 앱은 별도 -debug.apk를 사용합니다. 두 APK의 해시는 SHA256SUMS에서 확인할 수 있습니다.
