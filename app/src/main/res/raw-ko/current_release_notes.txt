이번 버전의 변경 사항

• 복구한 원래 모듈 서명키를 다시 적용했습니다. 기존 1328과 임시 1330에서 기본 APK 업데이트로 전환하며 보관함과 설정을 유지합니다.
• GitHub 정식 릴리스로 배포하여 앱의 업데이트 확인 화면에서 새 버전을 받을 수 있습니다.
• 접힌 전체 플레이어의 숨은 실행을 중단하고, 열 때만 화면을 구성합니다. 화면 상태는 보존하고 백그라운드의 UI 구독을 중단합니다.
• 대기열 전체 대신 다음 1~2곡의 로컬 음원만 준비하며, 셔플 순서를 반영하고 오래된 준비 대상을 해제합니다.
• 재생 중 자동 분석·추천 갱신·자동 파일 쓰기를 미루고, 실행 중 메모리 부족 신호에도 아트워크 캐시를 정리합니다.
• Google AI Studio, Groq, Cerebras, Hugging Face, OpenAI, Claude, Grok API를 선택적으로 연결할 수 있습니다. 제공자 선택·우선순위·폴백·요청별 순환을 지원합니다.
• 보낼 메타데이터를 확인한 뒤 개인 플레이리스트·곡·앨범 추천, 장르 찾기, 보관함 정보 수정과 공유 제안을 받을 수 있습니다. AI 버튼은 연결을 켠 경우에만 홈에 나타납니다.
• 정보 수정은 곡마다 검토하고 변경 전 기록으로 되돌릴 수 있습니다. 지원하는 Android 11+ 음원은 시스템 확인 후 휴지통으로 옮깁니다. AI가 명령을 실행하거나 원본 음원을 수정하지 않습니다.
